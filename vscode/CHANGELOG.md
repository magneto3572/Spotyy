# Changelog

## 0.0.7
First release for VS Code and VS Code–based editors (Cursor, Windsurf, VSCodium).
- Spotify controls in the status bar (macOS via AppleScript, Linux via MPRIS/playerctl), styled like the JetBrains plugin: round play/pause button with a live progress ring
- Listening Nearby sidebar: teammates on your LAN and what they're playing, vibe matches (same song / same artist)
- Focus Rooms: 25 / 45 / 60 min shared countdown, invite-only, host can remove members; ending the room closes it for everyone
- Ghost mode
- Wire-compatible with the Spotyy JetBrains plugin — IntelliJ and VS Code users see each other and share Focus Rooms
